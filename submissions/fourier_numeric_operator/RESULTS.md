# Learned Fourier numeric operator

This candidate represented soft decimal registers as normalized scalar
coordinates and used learned sinusoidal residual layers plus shared positional
digit queries.  It encoded no fixed arithmetic operation.

The 10-second fixed-modulus smoke completed 731 updates but reached only 2.33%
exact and 11.96% token accuracy.  The model did not learn even the small task,
so it was rejected before variable-modulus evaluation.
